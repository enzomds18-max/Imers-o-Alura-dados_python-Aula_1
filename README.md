Análise de Salários na Área de Dados (Pandas)

Projeto prático focado na exploração, tratamento e limpeza de dados de salários do mercado de tecnologia.


 Conceitos e Tecnologias Usadas:

* Biblioteca `pandas`: Leitura de CSVs remotos via URL (`pd.read_csv`)
* Exploração Inicial: Uso de `.head()`, `.info()`, `.shape` e `.describe()` para análise estatística e estrutura dos dados
* Tratamento e Renomeação: Tradução e renomeação de colunas do DataFrame (`df.columns`)
* Contagem de Frequência: Inspeção de categorias com `.value_counts()`
* Mapeamento e Substituição: Padronização de dados categóricos com `.replace()` para traduzir siglas (senioridade, tipos de contrato, modalidades de trabalho e tamanho das empresas)
